**3. Update `src/index.css` font imports:**

Replace the existing Google Fonts @import (line 2) with:

```css

@import url("https://api.fontshare.com/v2/css?f[]=satoshi@1,900,700,500,400&display=swap");

/* JetBrains Mono — tabular figures for numeric display */
@import url("https://fonts.googleapis.com/css2?family=JetBrains+Mono:wght@400;500;600&display=swap");
```

Key changes:

- Remove DM Sans from Google Fonts import (replaced by Satoshi as primary body font)
- Keep JetBrains Mono from Google Fonts (still needed for numbers)
- Fraunces loads via npm import in main.tsx (no @import needed in CSS)

**4. Update `:root` font-family stack (line 11-16):**

Replace the current DM Sans font-family with:

```css
font-family:
  "Satoshi",
  "DM Sans",
  -apple-system,
  BlinkMacSystemFont,
  system-ui,
  sans-serif;
```

DM Sans stays as explicit fallback for offline PWA mode (still cached by service worker from previous visits). Satoshi loads from Fontshare CDN when online.

**5. Add display font utility classes (after the existing `.tabular-nums` class around line 158):**

```css
/* Display serif for hero labels and section headers (>=24px only) */
.font-display {
  font-family: "Fraunces Variable", "Georgia", serif;
  font-variation-settings:
    "SOFT" 25,
    "WONK" 0,
    "opsz" 36;
}

/* Display serif for large hero numbers/labels (>=36px) */
.font-display-lg {
  font-family: "Fraunces Variable", "Georgia", serif;
  font-variation-settings:
    "SOFT" 20,
    "WONK" 0,
    "opsz" 48;
}
```

Do NOT use Fraunces below 24px — it's a display serif, illegible at small sizes. Numeric digits stay in JetBrains Mono (the `.tabular-nums` class handles this). Fraunces is for LABELS only ("Net take-home", "Gross annual", section headers).

**6. Update `index.html` — clean up font preconnect (lines 15-17):**

Remove the Inter Google Fonts link (line 17) — Inter is not used in the project:

```html

  href="https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700&display=swap"

```

Keep the preconnect hints for Google Fonts (JetBrains Mono still uses it). Add a preconnect for Fontshare:

