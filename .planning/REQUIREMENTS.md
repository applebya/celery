# Requirements: Celery Polish Milestone

**Defined:** 2026-02-01
**Core Value:** Quick, accurate salary conversion with tax estimates that's actually pleasant to use.

## v1 Requirements

### Scope Simplification

- [ ] **SCOPE-01**: Remove corporation employment type from UI and calculations
- [ ] **SCOPE-02**: Update any references/labels that mention corporation

### Desktop Experience

- [ ] **DESK-01**: Spacious layout with generous whitespace and breathing room
- [ ] **DESK-02**: Calculator takes up more horizontal space on wide screens
- [ ] **DESK-03**: Professional, refined visual hierarchy
- [ ] **DESK-04**: Results displayed prominently with clear information architecture

### Mobile Experience

- [ ] **MOB-01**: Clean, uncluttered mobile layout
- [ ] **MOB-02**: Touch-friendly input controls (appropriately sized tap targets)
- [ ] **MOB-03**: Smooth scrolling and interaction flow
- [ ] **MOB-04**: Key information visible without excessive scrolling

### Visual Polish

- [ ] **VIS-01**: Refined typography (font sizes, weights, line heights)
- [ ] **VIS-02**: Consistent spacing system throughout the app
- [ ] **VIS-03**: Modern aesthetic that feels current (not dated)
- [ ] **VIS-04**: Consistent component styling across all UI elements
- [ ] **VIS-05**: Polished transitions and micro-interactions

### Branding

- [ ] **BRAND-01**: Logo design (celery + money theme, literal style)
- [ ] **BRAND-02**: Favicon in multiple sizes
- [ ] **BRAND-03**: PWA app icons (192x192, 512x512)
- [ ] **BRAND-04**: Open Graph image for social sharing

(None — this is a focused polish milestone)
